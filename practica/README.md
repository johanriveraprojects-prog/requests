# Practice: Python + English (Práctica)

Each exercise is written in English with a Spanish glossary. Work on one at a time:
1. Read the instructions at the top of the file.
2. Complete the functions.
3. Run it: `python practica/ejercicio_NN.py`.
4. Write 3 to 5 sentences in English about what you did, and ask Claude to correct them.

Plan: week 1 Python basics, week 2 CSV/Excel with pandas, week 3 tests with pytest and Git, week 4 APIs with `requests`.
