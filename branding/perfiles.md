## Sistema de marca

| Elemento | AVX (madre) | ConstruAVX | ProduAVX |
|---|---|---|---|
| Esencia | Construir · Producir · Avanzar | Construcción inteligente | Producción en movimiento |
| Color base | `#111827` grafito | `#14213D` azul marino | `#0B3C49` azul petróleo |
| Color acento | `#FCA311` naranja + `#2EC4B6` turquesa | `#FCA311` naranja | `#2EC4B6` turquesa |
| Símbolo | "A" bicolor + "V" blanca + base | "A" naranja + "V" + viga | "A" turquesa + "V" + 3 puntos (línea de producción) |
| Archivos | `avx-logo.svg`, `avx-avatar.svg` | `construavx-logo.svg`, `construavx-avatar.svg` | `produavx-logo.svg`, `produavx-avatar.svg` |

**Regla de familia:** misma silueta (cuadrado redondeado + "A" + "V"), cada marca con su color. La madre combina el naranja de una y el turquesa de la otra.
**Tipografía:** Montserrat ExtraBold para el nombre y Montserrat SemiBold con espaciado para el eslogan.
**Tono de voz:** profesional, directo y cercano. Frases cortas, sin tecnicismos innecesarios.

## Coherencia entre perfiles

- Cada marca menciona a AVX ("Una marca de @avx.oficial") y AVX enlaza a las dos.
- Mismo orden de bio: **eslogan → qué hacemos → marca madre → ciudad → llamado a la acción**.
- Mismo estilo de publicaciones: fondo del color de la marca, acento en el segundo color y el logo en una esquina.
- Los tres perfiles usan el avatar cuadrado con esquinas redondeadas; las redes lo recortan en círculo sin perder el símbolo.
